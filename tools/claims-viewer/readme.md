# Claims Viewer

## Purpose

Displays and analyzes claims issued by Microsoft Entra External ID (B2C).

## Features

- Parse JWT claims
- Display custom attributes
- Review policy-specific claims
- Troubleshoot user flows

## Usage

```bash
claims-viewer.exe
```

## Inputs

- ID Token
- Access Token

## Outputs

- Decoded claims
- Claim values
- Validation results
